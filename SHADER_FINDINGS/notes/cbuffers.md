# Constant-buffer slots across the corpus (`dx_5_0`)

Generated by `SHADER_FINDINGS/scripts/cb_usage.py example_exports/shaders SHADER_FINDINGS/notes/cb_usage.json`. The JSON holds, per
container and per `cbN`: the largest declared size, how many programs declare it, the
immediate offsets read, and the bases of dynamically indexed reads (`cbN[rX + k]`).

A register slot is a binding point, not a buffer identity. A slot that has one size in
nearly every container that declares it, and is read at the same offsets, is treated here
as one shared buffer. Those are the rows marked shared.

## Compute and geometry

No slot has a consistent size across compute containers. Each compute shader carries its
own parameter block in `cb0`. The two geometry containers declare almost nothing.
